# Daily Expense Tracker

A web app to record and manage daily expenses, built as a final year BCA team project.

## Features
- Add, view, edit and delete expenses
- Login with username and password
- Password reset

## Tech Stack
PHP, MySQL, HTML, CSS, JavaScript

## How to Run
1. Clone or download this repository
2. Copy the `dets1` folder into `C:\xampp\htdocs`
3. Start Apache and MySQL in XAMPP
4. Open phpMyAdmin (http://localhost/phpmyadmin)
5. Create a database named `detsdb`
6. Import `database/detsdb.sql`
7. Open http://localhost/dets1/
